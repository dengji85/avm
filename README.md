## 📦 下载与安装

**不想自己打包？直接下载发布包即可。**

前往 GitHub Releases 页面下载最新版（Windows 单文件夹压缩包，解压即用）：

<p align="center">
  <a href="https://github.com/dengji85/avm/releases/latest">
    <img src="https://img.shields.io/github/v/release/dengji85/avm?label=下载%20最新版&color=1f6feb" alt="GitHub Release"/>
  </a>
</p>

1. 打开 **[Releases](https://github.com/dengji85/avm/releases)** 页面，找到最新版本的 `AVM-win64.zip`（或对应平台包）。
2. 下载后解压到任意目录（如 `D:\AVM\`）。
3. 双击 `AVM.exe` 启动，程序会自动打开浏览器进入 Web UI。
4. 数据（库文件 / 封面 / 配置）保存在 `AVM.exe` 同级的 `data/` 目录，整体拷贝即可备份迁移。

> 发布包已包含前端静态资源与全部后端模块，无需安装 Python 或 Node。若需要跨平台或自定义构建，见下方「快速开始 · 源码运行」。

## 🌟 本次更新亮点（1.9.0）

> 发布日期：2026-08-09 · 距离上一版（1.8.0 前端重构）的重点补强。

- **🤖 AV-Wiki 源真正后台自动抓取**
  新增 `app/cdp_fetch.py`：程序自管理常驻 headless Chrome（通过 Chrome DevTools Protocol），自动拉起、自动养信任度，**完全后台运行，无需手动开浏览器**。AV-Wiki 数据源从此可纳入常规后台采集任务，首次运行即可绕过 LiteSpeed 反爬验证页。
- **🖼 素人片封面补全**
  修复 JavBus 详情页 `#cover` 为空时未回退搜索结果页封面的问题，补全相对路径（`/imgs/cover/`、`/pics/cover/`）并自动为 cloudfront 图床带 `referer` 防盗链。实测为库存补回大量此前缺失的素人片封面。
- **🧭 筛选侧栏体验优化**
  影片数量一多，女优 / 厂商 / 系列等长尾维度的筛选项会爆棚。现改为：**低基数维度（类型 / 标记 / 评分 / 年份）置顶常驻**，女优 / 厂商 / 系列**默认折叠**，仅展示前 12 个热门 + 总数角标；组内值超过 20 条时提供**搜索框**快速定位，已选条件**自动置顶**。
- **🧹 发布产物更干净**
  `.gitignore` 补齐临时调试脚本（`_*.py` / `_*.html` / `_*.png`）、Chrome 调试 profile（`_cdp_profile/`）与本地数据库（`app.db`）等忽略规则，仓库不再混入运行残留。

完整变更见文末 **[更新日志](#更新日志)** 与 `CHANGELOG.md`。

## ✨ 它到底是什么 / 怎么用

一句话：**把你硬盘里那一堆命名乱七八糟、散落各处的 AV 文件，变成一处能检索、能策展、能回看的私人资料库。**

真实工作流是这样跑的：

1. **指定媒体库目录** → 工具递归扫描所有视频文件（默认跳过 sample/预告/花絮、回收站、`.git` 等噪声目录）。
2. **智能识别编号** → 从文件名/目录名解析标准番号，连 `IRO061C`、`SONE 760CH`、`300MAAN-123` 这种「字母紧贴数字、带版本尾巴」的野路子命名也能归一化成 `IRO-061` / `SONE-760`。
3. **多版本归并 + 内容去重** → 无码/有码/导剪/中字自动归到同一部；靠 `size + 内容哈希` 识别重复，库里不再躺着七八份同一部。
4. **一键刮削元数据** → 通过可插拔数据源（JavBus / JavDB / AV-Wiki / 本地 `.nfo`）补齐封面、女优、类型、厂商、系列、评分、简介；刮不到也能手动补。
5. **画廊浏览与分面检索** → 卡片墙 + 侧栏按女优 / 类型 / 厂商 / 系列 / 年份 / 评分 / 标记精准筛选，女优墙按出演数排，标签云一眼看偏好。
6. **片单与续播** → 手动清单 + 智能清单（按规则自动聚合）；续播进度自动记，列表直接看到看到哪、看没看完。
7. **（可选）AI 增强** → 兼容 OpenAI 协议的任意端点（云端或本地 Ollama）：详情页「生成简介 / 补充标签」，搜索框写自然语言「找几部有剧情、女主是老师的」自动翻出来。AI 未启用时自动降级为普通关键词检索。

全程本地运行，默认不联网上报，数据全在 `data/` 目录——**你的收藏，始终是你自己的。**

## 💎 核心价值

> **懂行的人，才懂这些痛。**

收藏几千部、硬盘换了一茬又一茬，可真正让人抓狂的从来不是「存不下」，而是——**存了之后根本找不到、看过了却记不清、想二刷却翻不到那一两部**。片匣就是给资深爱好者做的，专门治这些「老毛病」。

1. **番号一塌糊涂？智能识别替你收拾**
   普通软件搞不定的野路子命名，这里能自动识别、归一化，多版本归并 + 内容去重——**再也不会同一部在库里躺七八份**。还能识别分卷（`-cd1`/`_part2` 这类）避免误判重复。

2. **刮削失败、封面张冠李戴？**
   可插拔数据源 + 本地 `.nfo` 离线模式，一键补齐封面 / 女优 / 类型 / 系列；「数据健康」体检六类存储/元数据问题（缺失文件 / 分片不完整 / 缺封面 / 占位图 / 未识别番号 / 疑似重复）+ 四类劣质片筛查（广告样片 / 低码率 / 同番号劣质版 / 损坏）一眼看清，还能一键保留最佳版、清理冗余。

3. **「上次那部女主是老师的」——靠脑子想不如靠筛选**
   分面筛选按女优 / 类型 / 厂商 / 系列 / 年份 / 评分 / 标记精准定位；女优墙、标签云、片单（手动 + 智能规则自动聚合）、相似推荐，把「囤」变成「能翻出来看」。

4. **看到一半被打断？进度接着来**
   **零配置观看监控**：把文件丢给系统默认播放器（VLC/PotPlayer/MPC/mpv），后端后台线程通过文件占用探测自动还原「看了多久 + 哪几段」，落库到观看历史。列表上直接看到看到哪、有没有看完；相似推荐和「我的观影」偏好分析让「下一部看啥」不用纠结。

5. **库脏了？一键体检看清**
   **数据健康**：六类问题（缺失文件 / 分片不完整 / 缺封面 / 占位图封面 / 未识别番号 / 疑似重复）直观汇总，支持一键「重解析番号」「刮削缺失」；另有**劣质片筛查**四类（广告样片 / 低码率压片 / 同番号劣质版本 / 损坏不完整），一键保留最佳版、清理冗余。

6. **怕被平台关、怕隐私漏、怕换电脑全没了？**
   全本地、无账号、不联网上报，数据就在 `data/` 目录里，拷走即用。AI 也走你自己的端点，密钥只发给你配的地址。

7. **给同好，也来自同好**
   前后端一体、单命令打包成免安装版本，能直接在自家设备上跑、能随手发给朋友。数据源、AI、甚至自定义 JSON/HTML 抓取规则都是可插拔的——你熟悉哪路资源，就接哪路。

| **自动扫描建库** | 递归扫描目录，剥离站点/发布组/技术噪声，自动跳过 `sample`/`预告`/回收站等；小于 `min_size_mb` 的预览片直接忽略。 |

| **元数据刮削** | 可插拔数据源（JavBus / JavDB / AV-Wiki / 本地 `.nfo` / 自定义 HTTP-JSON / 自定义 HTML 规则），抓取封面、女优、类型、系列、厂商、导演、评分、简介；跨源回退补全素人片封面（`app/scraper.py`、`app/providers/`）。 |
| **AV-Wiki 后台采集** | 通过 Chrome DevTools Protocol 自管理常驻 headless Chrome（`app/cdp_fetch.py`），完全后台自动抓取，无需手动开浏览器，绕过 LiteSpeed 反爬。 |
| **画廊与分面筛选** | 卡片墙 + 侧栏分面筛选：低基数维度（类型/标记/评分/年份）置顶常驻，女优/厂商/系列等长尾维度折叠 + 组内搜索 + 已选置顶。 |
| **详情抽屉** | 系统/内置播放、续播进度、**相似推荐**、收藏/评分/想看、AI 简介与补充标签。 |
| **语义搜索** | 自然语言描述经 AI 解析为结构化检索条件（关键词/类型/女优/厂商/系列/年份），自动套用并展示结果；AI 未启用时降级为关键词检索（`app/ai.py`）。 |
| **AI 增强（可选）** | 详情页「生成简介 / 补充标签」；兼容 OpenAI 协议端点（云端或本地 Ollama，免 Key）。 |
| **零配置观看监控** | 后台线程探测系统播放器对文件的占用，还原观看区间与总时长，落库观看历史（Windows 用独占锁探测，零依赖播放器内部接口）（`app/monitor.py`）。 |
| **数据健康体检** | 六类汇总：缺失文件 / 分片不完整 / 缺封面 / 占位图封面 / 未识别番号 / 疑似重复；一键「重解析番号」「刮削缺失」（`/health-check`）。 |
| **劣质片筛查** | 四类劣质片：广告样片 / 低码率压片 / 同番号劣质版本 / 损坏不完整；一键保留最佳版、清理冗余（`dedupe.scan_quality`）。 |
| **统计可视化** | 标签云、观看日历热力图、时长/年份分布、收藏与评分分布、女优出演数排行。 |
| **片单管理** | 手动清单与智能清单（按规则自动聚合）。 |
| **女优墙 / Rich 档案** | 按出演数排序的头像墙；女优详情页含统计、分布图与代表作。 |
| **主题与密度** | 暗色/亮色 + 紧凑/舒适密度，偏好本地持久化。 |

## 🆚 与同类开源刮削 / 媒体管理工具的区别

市面上的开源方案大致分两类：**通用媒体刮削器**（TinyMediaManager、MediaElch、XBVR 等，影视为主、AV 只是勉强兼容）和**各类 JAV 管理脚本/小工具**（JAVLibrary 配套、自建番号查询脚本等，能力单一）。片匣的定位是**专为 AV 收藏做领域适配的一站式本地资料库**：

| 维度 | 通用刮削器（TMM / MediaElch / XBVR 等） | 自建 JAV 脚本 / 小工具 | **片匣 AVM** |
| --- | --- | --- | --- |
| **番号识别** | 仅规范命名；野路子（紧贴数字、带版本尾巴、素人编号）常落空 | 通常只做单源查号，无统一归一化 | 专用解析器覆盖 7 类规则（FC2/HEYZO/XXX-AV/MARKET/DATE-NUM/TOKYO-HOT/STANDARD），归一化 + 标记识别（字幕/无码/VR/分卷） |
| **多版本/去重** | 多版本需手动管理；缺内容级去重 | 基本无 | 自动归并 + `size+哈希` 内容去重，分卷不误判 |
| **AV 元数据** | 对 AV 编目弱、封面常张冠李戴 | 依赖单一站点，挂了就空 | 多源可插拔（JavBus/JavDB/AV-Wiki/.nfo）+ 跨源回退；素人片封面也能从搜索结果页补回 |
| **反爬源采集** | 不涉及 AV-Wiki 这类强反爬源 | 往往要手动开浏览器养信任 | AV-Wiki 经 Chrome DevTools Protocol **后台自动抓取**（自管理 headless Chrome，无需手动开浏览器） |
| **内容策展** | 以「文件夹」为中心 | 基本只有列表 | 以「番号/作品」为中心：女优墙、标签云、智能片单、相似推荐 |
| **观看回归** | 需播放器插件/客户端；中断难续播 | 无 | 零配置监控任意系统播放器，自动记录区间、续播进度、「我的观影」分析 |
| **库健康** | 基本无 | 无 | 六类数据健康体检 + 四类劣质片筛查，一键保留最佳版、清理冗余 |
| **AI 增强** | 多数无 | 无 | 可选：语义搜索、生成简介、补充标签（兼容任意 OpenAI 协议端点，本地 Ollama 免 Key） |
| **部署形态** | 多为桌面 GUI / 常驻服务 | 脚本散装、无界面 | 纯本地 Web、无账号、前后端一体、单命令打包免安装 exe，数据全在 `data/` |
| **可扩展** | 插件生态有限、AV 适配少 | 改起来靠自己 | 数据源、AI、自定义 JSON/HTML 抓取规则均可插拔 |

> 简言之：它不是又一个「能放视频的网页」，而是**为 AV 收藏这个特殊领域做了大量领域适配（番号、去重、素人、观看回归、体检）的本地资料库**。

## 🚀 快速开始

### 方式一：源码运行（推荐开发）

```bash
# 1. 安装后端依赖
pip install -r requirements.txt

# 2. 启动后端（默认 http://127.0.0.1:8770）
python run.py serve

# 3. 启动前端开发服务器（默认 http://localhost:5173）
cd web_src
npm install
npm run dev
```

浏览器打开 `http://localhost:5173` 即可。

### 方式二：构建前端后整体托管

```bash
cd web_src && npm install && npm run build   # 产物输出到 web_dist/
python run.py serve                          # 服务直接托管 web_dist/
```

### 打包为可分发包

```bash
python build.py          # 生成单目录打包到 dist/片匣/片匣.exe
```

## ⚙️ 配置

配置存于 `data/config.json`（与缺省值合并），主要段：

- `library.paths`：扫描根目录；`min_size_mb` 跳过预览片；`ignore_keywords` / `ignore_dirs` 跳过噪声。
- `scraper`：启用的数据源与顺序（`avwiki / javbus / javdb / local_nfo`）、代理、Cookie、并发数、请求间隔；支持自定义 `http_json` / `http_html` 规则。
- `media`：头像/背景图落盘目录与开关（支持独立磁盘）。
- `ai`：可选 AI 端点（`enabled` / `base_url` / `api_key` / `model` / `temperature`）。

也可在图形界面的「设置」页修改，无需手改文件。
