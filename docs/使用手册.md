# 片匣 · 使用手册

一份面向日常使用的完整操作指南。无论你是**从源码运行**、**双击打包版 exe** 还是 **Docker 部署**，本手册都适用。

> 架构与实现细节见 [开发文档](开发文档.md)；安全设计见 [安全与隐私设计](安全与隐私设计.md)；FFmpeg / 语音识别安装见 [扩展组件手册](扩展组件手册.md)；Docker 见 [Docker部署](Docker部署.md)。版本变更见根目录 [CHANGELOG](../CHANGELOG.md)。

## 0. 运行与升级

### A. 源码运行（开发 / 调试）

```bash
pip install -r requirements.txt
python run.py
```

浏览器自动打开 <http://127.0.0.1:8770/>。常用参数：

```bash
python run.py --port 9000        # 换端口
python run.py --host 0.0.0.0     # 允许局域网其它设备访问
python run.py --no-browser       # 不自动开浏览器
```

### B. 打包版（随拷随用）

直接双击 `AVM.exe`（单个文件，前端资源已内嵌）。关闭弹出的命令行窗口即停止服务。所有数据与配置都在 `exe` 同级的 `data/` 目录里。

**升级只需复制这一个 exe**：下载新版覆盖旧版即可，`data/`（库、封面、配置、进度）原地保留。详见 **[升级指南](升级指南.md)**。

### C. Docker

镜像已预装 FFmpeg；数据落在挂载卷。详见 **[Docker部署](Docker部署.md)**。

### 命令行工具

除 `serve` 外还有几个子命令（`python run.py <子命令>`）：

| 子命令 | 用途 |
| --- | --- |
| `scan` | 命令行执行一次扫描（可配 `--host` 等参数） |
| `ai-check "一句话"` | AI 诊断：打印模型配置、库字典、这句话的实际解析步骤与命中条数，排查「为什么查不出」 |
| `web-check "查询词"` | 联网搜索自检：验证搜索后端配置并真实搜索一次 |
| `mcp` | 启动 MCP 服务器（供支持 MCP 的外部 AI 客户端只读查询库），可选依赖见 `requirements-mcp.txt` |

## 1. 首次使用：建库

1. 打开 **设置** 页，在「媒体库目录」点 **浏览…** 选择你放影片的盘符 / 文件夹（可加多个）。
2. 点 **保存设置**。
3. 点 **扫描媒体库**。扫描会：
   - 递归遍历目录，按扩展名与最小体积过滤；
   - 自动跳过 `sample / 预告 / 花絮 / 特典` 等关键字和样片，跳过 `.part` `.!qB` 等下载临时文件；
   - 从文件名提取番号、归并 `-cd1/-cd2` 之类的分片；
   - 探测文件是否**真的自带中文字幕**（与站点标注的「中字」分开记录）；
   - 嗅探同目录封面 → 拉取元数据 → 补全女优 / 类型 / 厂商等。
4. 扫描完成回到 **馆藏** 即可浏览。

> 扫描是增量且幂等的：**移动 / 改名会被自动识别并更新记录**，不会留下失效的重复条目。字幕只对新增或变更过的文件探测一次。
>
> 文件在磁盘上消失后，记录先标记为**缺失**并保留一段时间（默认 **30 天**，见「设置 → 媒体库 → 缺失宽限期」），超过宽限期才清理记录。**扫描与清理都不会删除硬盘上的视频文件。**

## 2. 馆藏画廊

* **缩略卡**：封面 + 番号 + 标题 + 女优 + 时长/日期；有评分显示 `★N`，已收藏显示 ♥。
* **排序**：默认「最近添加」；另有评分最高、多人优先、标题、日期、时长、随机等共 10 种。
* **网格密度**：工具栏「密度」按钮在 **宽松 / 紧凑** 间切换。
* **批量操作**：多选后底部批量栏可批量评分、标记已看/未看、追加或替换类型与女优、移出媒体库。
* **点击卡片**：打开右侧详情抽屉。

## 3. 检索

检索条件全部叠加生效（交集）：

| 维度 | 操作 |
| --- | --- |
| 关键字 | 顶部搜索框，匹配番号 / 标题 |
| 女优 | 侧栏多选；默认 **OR（任一满足）**，可切 **AND（同时出现）** |
| 类型 / 标签 | 侧栏多选 |
| 评分 / 标记 | 侧栏滑块 / 固定标签 |
| 厂商 / 系列 / 前缀 / 年份 | 侧栏下拉或输入 |

> **侧栏长尾维度**（女优 / 厂商 / 系列）默认折叠，仅展示数量最高的前 12 个；点击表头展开，值超过 20 个时出现组内搜索框。已选中的值始终置顶。
>
> 启用 AI 后搜索框右侧出现 **AI** 按钮，可用自然语言找片（见第 10 节）。

## 4. 详情抽屉（核心交互）

点任意卡片打开。**所有操作都在主区分组平铺，全部一级可见**：

### 播放组
* **在线播放 / 继续**：浏览器直接流式播放（支持断点续传与进度记录）；有进度时按钮显示「继续 xx%」。
* **外部播放**：用系统默认播放器打开（任何播放器都行，观看时长也会被记录）。
* **投屏**：自动扫描同网段 DLNA 设备（电视 / 盒子），点一下即投；扫不到时可手动填设备 IP。投屏中操作区会保留一个状态按钮，点它即断开。

### 标记组
* **评分**：星星区点 1–5 星。
* **♥ 收藏 / ⌚ 想看 / ● 已看**：一键切换。
* **＋ 加入合集**：弹层选择合集，可新建。
* **📁 打开文件夹**：在资源管理器中定位影片文件。
* **✨ AI 助手**：打开 AI 助手面板（见第 10 节）。

### 站点组
* 启用的在线站点（设置里配置）按番号一键打开对应页面；前 3 个平铺，其余在「更多(n)」里。

### 维护组
* **⟳ 重新刮削**：重拉元数据。
* **⤓ 导出到媒体目录**：把这部影片的 NFO + 封面写到媒体目录（Emby/Jellyfin/Kodi 用）。
* **🖼 清除封面**。

### 内容标签页
* **预览**：生成预览图墙（需 FFmpeg；**未配置 FFmpeg 时才会出现提示**，配置好即不再提示）。路径在 **设置 → 扩展组件** 安装配置。
* **信息**：简介（可编辑）、笔记、AI 快捷（写简介 / 建议标签）、关键信息、自定义标签（可增删、点击即筛选）。
* **文件**：文件清单与状态；底部「危险操作」三种删除方式（见下）。

### 删除影片与文件（文件标签页 → 危险操作）

| 方式 | 行为 | 可否恢复 |
| --- | --- | --- |
| **从库中移除** | 只删数据库记录，磁盘文件原样保留 | 重新扫描即可找回 |
| **删除到回收站** | 影片文件移入系统回收站，再移除记录 | 可还原（推荐） |
| **删除影片和文件** | 永久删除磁盘文件 | **不可恢复** |

### 外部删除（手动删文件 / 磁盘掉线）

文件消失后：**快速核对缺失**（维护页，秒级）→ 标记缺失并计时 → 宽限期内搬回原处扫描即恢复 → 超过宽限期（默认 30 天）才清理记录。整个过程**不删除磁盘文件**。

### 键盘流

| 键 | 作用 |
| --- | --- |
| `/` | 聚焦搜索框 |
| `r` | 随机打开一部作品 |
| `←` / `→` | 详情抽屉里上 / 下一部 |
| `f` | 收藏 / 取消收藏 |
| `Esc` | 关闭抽屉 / 清空筛选 |

## 9. 观看历史与我的观影

* **会话级历史**：点「系统播放」或「内置播放」都会记一场（开始/结束、时长、是否看完）。**系统播放器也有详细记录（零配置）**：后端探测文件被占用的时间段，合并为观看区间——VLC / PotPlayer / mpv 等都自动记录，MKV / H.265 也能记。
* **真实分段（内置播放器）**：记录实际观看区间 `[起点, 终点]`，详情页「观看历史」的覆盖条一眼看出看了哪几段。
* **我的观影**：基于真实观看时长聚合——总览、偏好画像（类型/女优/厂商/系列/导演）、活跃时段热力图、观看最多的影片与最近观看。

## 10. AI 助手

本工具不内置任何模型，但提供**兼容 OpenAI 协议**的可插拔接入层：云端（OpenAI / 硅基流动 / DeepSeek / 通义等）或本地 **Ollama**（`http://127.0.0.1:11434/v1`，`ollama pull qwen2.5` 后免 key）。所有调用均为本地发起，密钥只发往你配置的端点。

### 10.1 接入模型（AI 中心）

**AI 中心**（设置页右上「打开 AI 中心」或侧栏入口）集中了模型、提示词、批量任务、调用记录、术语表：

| 字段 | 说明 |
| --- | --- |
| 启用 AI | 总开关，开启后才出现 AI 能力 |
| 模型 | `deepseek-chat` / `gpt-4o-mini` / `qwen2.5` 等；可配**多个模型**（不同端点/key），指定默认模型 |
| 温度 | 0–1，越低越稳定（默认 0.4） |

* **问库隐私**（AI 中心 → 模型页）：把「问库」的聚合统计摘要发给云端模型润色前需显式开启；女优名单有独立子开关；本地 Ollama 自动全量、数据不出本机。
* **联网搜索**（AI 中心 → 模型页）：给助手的「查网络资料」技能配搜索后端，二选一：
  * **SearXNG**（免费，推荐自建）：填实例地址，如 `http://127.0.0.1:8080`。需在实例的 `settings.yml` 里给 `search.formats` 开启 `json`；
  * **Tavily**：填 API Key（有免费额度）。
  * 填好后点 **测试连接** 自检（「实例没开 JSON」「限流」「Key 无效」都会给出人话提示）。**不配置 = 助手完全不联网**，行为与以前一致。查询词（番号等）会发给所配服务。

### 10.2 助手面板与能力选项

右下角 ✨ 悬浮球任意页面唤起（可在设置 → 外观关闭）；详情页也有「✨ AI」入口。**不用想措辞，点输入框上方的能力按钮即可**：

* **影片模式**（已打开详情）：
  * **影片资料**：番号、标题、发行、时长、片商、系列、女优、评分、分辨率、体积、字幕——纯本机元数据，不花 token；
  * **查网络资料**：联网搜索这部片的剧情、口碑并汇总（需先配置搜索后端）；
  * **这部讲什么**：生成剧情简介（优先读字幕，没字幕按元数据兜底并注明依据）；
  * **找类似的 / 补几个标签 / 翻译字幕**；有字幕时还有 **问剧情**（只依据字幕回答并标注 `[分:秒]` 依据）。
* **库模式**（未打开详情）：
  * **找片类**：今晚看什么 / 最高评分未看 / 有中文字幕 / 4K 高清 / 没封面；
  * **统计类**：看了多少 / 口味画像 / 今年口味 / 库体检 / 最近入库——统计在本机执行，模型只负责理解问题，库数据不出本机；
  * 直接打字：**自然语言找片**（如「找一下丝袜的、年纪大一点的」）。

### 10.3 多步 agent：步骤可见、流式输出

有模型时，助手是**多步 agent**：先看库里实际有哪些类型/标签（库字典），再检索；查不到会自己换同义词或放宽条件再试，最后给一句话结论。

* **步骤实时可见**：每完成一次工具调用，结果卡上立刻多一行（「检索 · 1 条（連褲襪）· 2ms」）；
* **流式输出**：结论逐字打出，不用等十几秒；
* **全屏**：标题栏 ⛶ 一键铺满（ESC 退出），全屏时影片卡保持海报尺寸多列铺开；
* **历史可复制**：悬停自己发过的消息出现复制按钮；对话与答案都可直接划选复制；
* **指代保护**：没打开影片时问「这部讲什么」，助手会提示先打开影片或直接给番号，不会瞎搜。

### 10.4 联网查资料（可选）

影片缺元数据时说「这部讲什么，网上查查」或「IPX-123 搜一下剧情」：

1. 助手会搜索（用番号效果最好）→ 抓取网页正文 → 汇总成带**来源域名**的回答；
2. 抓不到的就明说，绝不凭记忆编；
3. 结果卡上能看到「联网查询 · N 条结果」的实时步骤；
4. 没配置搜索后端时，助手会告诉你去 AI 中心配置，**不会擅自联网**。

### 10.5 详情页 AI 快捷

* **写简介**：就地生成、新旧对照、点「采用」才写库；来源与时间会标注在简介下方；
* **补充标签**：建议 3–8 个中文标签，可追加；
* **AI 字幕翻译**：选目标语言（简/繁/英）与是否双语，生成 `.srt` 存到 `data/subs/<影片id>/`，可下载/删除；
* **批量任务**（AI 中心 → 批量任务）：对最近 N 部批量「字幕翻译」或「剧情分析」，可取消，可按字符预算限制；
* **翻译术语表**（AI 中心 → 术语表）：每行「原文 = 译名」，女优名/系列名建议放这里，翻译严格照译。

## 11. 维护中心

顶栏「管理」分组进入。标签页：**概览 / 存储健康 / 字幕 / 刮削失败 / 日志 / 导出媒体库**。

### 概览
待办与关键指标一览（缺封面、未识别、失败数等），点条目直达处理。

### 存储健康
六类体检：**缺失文件 / 分片不完整 / 缺封面 / 占位图封面 / 未识别番号 / 疑似重复**，支持「重解析番号」「刮削缺失」一键修复；「劣质片筛查」标签聚焦广告样片 / 低码率 / 同番号劣质版 / 损坏片，可勾选后一键「保留最佳版 / 清理」。

### 字幕匹配
让系统播放器自动加载字幕：选择下载好的字幕文件（可多选）→ **匹配选中文件**（按番号自动配对）→ 勾选 **对齐选中字幕**（重命名为视频同名并放到影片同目录，可选保留字幕包原件）。

### 刮削失败原因
把「为什么没刮到」摊开：逐源状态明细，失败按 **反爬拦截 / 网络错误 / 源无此片 / 解析失败 / 番号异常** 五类分组；支持 **一键重试网络/拦截项**、勾选后 **换源重抓**。

### 日志
扫描 / 刮削历史与「跳过名单」（可解除跳过）。

## 12. 导出到媒体目录（Emby / Jellyfin / Kodi）

**维护 → 导出媒体库**。把 NFO + 封面按媒体服务器的目录结构写到媒体目录：

* **开始导出**：全库导出为后台任务，按钮上直接显示进度（`12/48`）与进度条，**不卡界面**；串行温和写入，不影响播放/扫描；重复导出时按冲突策略跳过已导出的，很快。
* **取消**：导出中可点取消，当前这部写完即停（不留半截文件），已导出的不受影响。
* **导出设置**（折叠，首次使用展开）：启用开关、写 NFO / 封面 / fanart、图片命名（numbered / plain）、NFO 命名（与视频同名 / movie.nfo）、冲突策略（跳过 / 合并 / 覆盖）、**路径映射**（每行「本地路径 => 媒体库路径」，兼容 Docker/网盘映射）、完成后通知 Emby 刷新。
* **Emby / Jellyfin 服务器联动**（自动刷新库）在 **设置 → Emby 面板** 配置地址与 API Key，可测试连接、手动刷新。

## 13. 访问令牌与手机访问

**设置 → 访问**，只有「一个令牌 + 一个开关」：

* **访问保护（唯一开关）**：默认开启——所有设备（含本机）首次访问都要输入访问令牌，登录后默认 7 天免输。关闭后局域网内任何人可见全部内容（页面有红字警告）。
* **访问令牌**：默认只显示掩码；点「显示」需**再输一次当前令牌**，明文 30 秒后自动隐藏。可自定义（≥8 位），或「立即登出并更换令牌」一次完成换新 + 踢掉所有设备。容器内 `cat /data/access_token.txt`。
* **扫码访问**：二维码里是**一次性短链**（默认 5 分钟、扫一次即失效），不含长期令牌。容器 / NAS 用 `AVM_PUBLIC_URL`（或 `server.public_url`）指定对外地址。
* **防火墙放行**（手机打不开时，管理员命令提示符执行设置页给出的命令）：

  ```bat
  netsh advfirewall firewall add rule name="AVM" dir=in action=allow protocol=TCP localport=<端口> profile=any edge=yes
  ```

* **遮挡与解锁**（设置 → 隐私）：空闲自动锁定默认 30 分钟（看片不算空闲）、老板键 `Ctrl+Shift+H`、「启动即遮挡」；解锁用 4–6 位快速解锁码或访问令牌；登录可勾「记住此设备 30 天」，受信设备可管理。
* **接口文档**：登录状态打开 `/api/docs` 查看全部接口与 curl 示例（离线可用）；原始规格在 `/api/openapi.json`。想未登录也可看：设置 → 访问 → 高级 → 公开接口文档。
* **两步验证**：设置 → 安全 可启用 TOTP（Authy / Google Authenticator 等）。

## 14. 定时自动扫描

**设置 → 自动扫描** 填周期（分钟），后台按周期执行增量扫描自动入库；`0`（默认）关闭。扫描在后台执行，不与手动扫描冲突。

## 15. 常见问题

**扫描不到文件？**
检查「最小文件体积」（默认 100MB）和「视频扩展名」；测试小文件把体积设为 0。

**封面全是占位图？**
封面优先级：同目录图片 → 元数据源 URL → 手动上传 → 番号占位图。可批量嗅探本地封面，或详情页手动上传。仍显示旧图请硬刷新（`Ctrl+Shift+R`）。

**「从库中移除」会删视频吗？**
不会，只删数据库记录。

**数据怎么备份 / 迁移？**
整个 `data/` 目录拷走即可。

**AI 助手没反应 / 查不出？**
1. 设置 → AI 中心确认已启用并填好端点与模型；
2. 用 `python run.py ai-check "你的问题"` 诊断：会打印模型配置、库字典、解析步骤与命中数；
3. 模型路径失败时助手会在结果卡上显示降级原因（不会静默）。

**联网查资料不可用？**
AI 中心 → 联网搜索：SearXNG 需开启 `json` 输出（403 提示就是这个），Tavily 需有效 Key；点「测试连接」看人话提示，或 `python run.py web-check "查询词"` 自检。

**AI 字幕翻译 / 预览图不可用？**
维护页相关功能依赖 **FFmpeg / 语音识别组件**，在 **设置 → 扩展组件** 一键安装（详见 [扩展组件手册](扩展组件手册.md)）；配置好后详情页不再出现「需要 ffmpeg」提示。

## 16. 使用须知

* 本工具仅用于管理**用户自己合法持有**的本地媒体文件，不提供、不索引、不下载任何影片内容。
* 联网数据源（元数据源 / 联网搜索）需由使用者自行配置，请遵守目标站点的服务条款及所在地区法律法规。
* AI 功能发送的内容范围见「问库隐私」与联网搜索的说明；密钥只发往你配置的端点。
