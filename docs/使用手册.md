# AV 博物馆 · 使用手册

一份面向日常使用的完整操作指南。无论你是**从源码运行**还是**双击打包好的 exe**，本手册都适用。

---

## 0. 两种运行方式

### A. 源码运行（开发 / 调试）

```bash
pip install -r requirements.txt
python run.py
```

浏览器自动打开 <http://127.0.0.1:8770/>。

常用参数：

```bash
python run.py --port 9000        # 换端口
python run.py --host 0.0.0.0     # 允许局域网其它设备访问
python run.py --no-browser       # 不自动开浏览器
```

### B. 打包版（随拷随用）

直接双击 `dist/AV博物馆/AV博物馆.exe`。它等价于「源码 + 内置数据 + 自动开浏览器」。
关闭弹出的命令行窗口即停止服务。所有数据与配置都在 `exe` 同级的 `data/` 目录里。

> 打包版同样支持 `--port` / `--host` / `--no-browser` 等命令行参数（在 exe 上右键「发送到 → 命令行」或直接 `AV博物馆.exe --port 9000`）。

## 1. 首次使用：建库

1. 打开 **设置** 页，在「媒体库目录」点 **浏览…** 选择你放影片的盘符 / 文件夹（可加多个）。
2. 点 **保存设置**。
3. 点 **扫描媒体库**。扫描会：
   - 递归遍历目录，按扩展名与最小体积过滤；
   - 自动跳过 `sample / 预告 / 花絮 / 特典` 等关键字和样片；
   - 从文件名提取番号、归并 `-cd1/-cd2` 之类的分片；
   - 嗅探同目录封面 → 拉取元数据 → 补全女优 / 类型 / 厂商等。
4. 扫描完成回到 **馆藏** 即可浏览。

> 扫描是增量且幂等的：改了文件名或移动了文件，重新扫描即可；媒体库目录里已不存在的记录会被自动清理（**不会删除硬盘上的视频**）。

## 2. 馆藏画廊

* **缩略卡**：封面 + 番号 + 标题 + 女优 + 时长/日期；有评分时显示 `★N` 徽标，已收藏显示 ♥。
* **排序**：默认「最近添加」；另有 `评分最高`、`多人优先`（共演女优越多的越靠前）、`标题`、`日期`、`时长`、`随机` 等共 10 种。
* **网格密度**：工具栏「密度」按钮在 **宽松 / 紧凑** 间切换，紧凑模式一屏多看约 1.7 倍作品。
* **点击卡片**：打开右侧详情抽屉。

## 3. 检索

检索条件全部叠加生效（交集）：

| 维度 | 操作 |
| --- | --- |
| 关键字 | 顶部搜索框，匹配番号 / 标题 |
| 女优 | 侧栏多选；默认 **OR（任一满足）**，可切 **AND（同时出现）** |
| 类型 | 侧栏多选 |
| 厂商 / 系列 / 前缀 / 年份 | 侧栏下拉或输入 |

> **多人共演小知识**：库里大部分是单人 solo 片。多选女优选「同时出现（AND）」往往会得到 0 条，
> 所以默认改成 **OR（任一满足）**——只要作品里有你选的任意一位就返回；想进一步收敛再切回 AND。

## 4. 详情抽屉（核心交互）

点任意卡片打开。抽屉里可以：

* **看图 / 看信息**：大封面、女优、类型、厂商、系列、日期、时长、简介。
* **评分**：右上角五颗星，点一下打 1–5 星；点已选星或「清除」取消评分。评分会写回数据库，卡片显示 `★N`，可按「评分最高」排序、**已评分** 筛选。
* **收藏**：♥ 按钮或键盘 `f`，收藏状态实时同步。
* **播放 / 定位**：用系统默认播放器直接播放；「在文件夹中显示」定位到文件。
* **导出**：NFO（Kodi/Emby 格式）或 CSV。
* **女优合作网 / Rich 档案**：在女优名字旁进入该女优详情，页面会列出 **最常合作的女优（Top 12）**，点击同伴即跳到「该女优 + 同伴」的 OR 筛选。详情页已升级为数据化 **Rich 档案**：
  * 头部含头像、收藏 ♥ 与「✎ 编辑」按钮（可填别名 / 生日 / 备注，写回数据库）。
  * **统计卡片**：作品数、活跃年份（首演–最新）、总时长、平均评分、总体积、已看 / 收藏。
  * **分布条形图**：类型 / 厂商 / 系列三张，点击任意条目直接跳到对应筛选。
  * **代表作**：按评分取高分 Top4 卡片。

### 键盘流（全程不用鼠标）

| 键 | 作用 |
| --- | --- |
| `/` | 聚焦搜索框 |
| `r` | 随机打开一部作品 |
| `←` / `→` | 详情抽屉里上 / 下一部 |
| `f` | 收藏 / 取消收藏当前作品 |
| `Esc` | 关闭抽屉 / 清空当前筛选 |

## 5. 快速筛选条

工具栏下方有一排快捷按钮，点击即筛选，再点取消；按钮右侧带数量角标：

* **随机一部** 不开筛选，而是随机打开一部详情。
* **只看收藏**：`favorite = 1`。
* **未看**：没有观看记录的作品。
* **想看清单**：加入了 watchlist 的作品。
* **多人共演**：女优数 ≥ 2 的作品。

## 8. 设置

* **媒体库目录 / 最小体积 / 扩展名 / 忽略关键字**：控制扫描范围。
* **元数据源**：本工具不内置第三方站点抓取规则，需自行在「元数据源」里填写地址与解析规则，并确认对目标站点有合法权限。内置三类可插拔源：
  * `local_nfo`：读取影片同目录的 `.nfo` / `.json`（完全离线，推荐已有 Kodi/Emby 库的用户）。
  * `http_json`：对接你自建的 JSON 接口。
  * `http_html`：按 CSS 选择器解析网页。
* **番号识别测试**：粘贴文件名即时预览识别结果，方便校验命名规范。
* **AI 增强**：见下方「AI 与语义搜索」一节。

> **番号识别已支持「字母紧贴数字」格式**：如 `IRO061C`、普通电影 `SONE 760CH` 等尾随版本/版本字母的命名，现在也能正确解析为 `IRO-061` / `SONE-760`，无需改名即可匹配元数据。

## 9. 数据健康（体检与修复）

「数据健康」页（顶栏「管理」分组 → **数据健康**）扫描库内数据质量问题，分六类汇总：

* **缺失文件**：数据库有记录但磁盘文件已不存在。
* **分片不完整**：多集影片（如 `-cd1`）缺少后续分片（如 `-cd2`）。
* **缺封面**：尚未获取到任何封面图。
* **占位图封面**：封面为无效占位图（如 DMM 无封面图），需手动替换。
* **未识别番号**：未能从文件名解析出番号（可点「重解析番号」尝试用目录/标题重新识别）。
* **疑似重复**：文件大小完全相同的影片（可能是同一片重复入库）。

每类卡片列出受影响影片（点条目直达详情），并可一键修复：

* **重解析番号**：仅对未识别的记录，用文件名/目录名候选重新解析番号（不会覆盖已有正确番号）。
* **刮削缺失**：仅拉取缺失元数据的影片。

> 这是对旧版「文件体检」（设置 → 存储）的补充，差异在于：文件体检跑的是存储级五类检查，数据健康页额外聚焦**番号识别**与**占位图**这类元数据质量问题，且提供一键重解析入口。

## 10. AI 与语义搜索（可选增强）

本工具不内置任何 AI 模型，但提供**兼容 OpenAI 协议**的可插拔接入层：可用云端（OpenAI / 硅基流动 / DeepSeek / 通义等），也可用本地 **Ollama**（`http://127.0.0.1:11434/v1`，`ollama pull qwen2.5` 后免 key）。所有调用均为本地请求，密钥只发往你配置的端点。

### 配置（设置 → AI 增强）

| 字段 | 说明 |
| --- | --- |
| 启用 AI | 总开关，开启后详情页与搜索框才出现 AI 能力 |
| Base URL | `https://api.openai.com/v1` 或 `http://127.0.0.1:11434/v1` |
| API Key | 云端/中转必填；本地 Ollama 留空 |
| 模型 | `gpt-4o-mini` / `deepseek-chat` / `qwen2.5` 等 |
| 温度 | 0–1，越低越稳定，越高越发散（默认 0.4） |

### 详情页 AI 按钮

打开任意作品详情，若已启用 AI，操作区出现两个按钮：

* **AI 生成简介**：依据番号/标题/女优/类型等元数据，生成或润色一段客观中文简介，写回数据库。
* **AI 补充标签**：建议 3–8 个中文标签，可追加到影片标签。

### 语义搜索

搜索框在 AI 启用后右侧出现 **AI** 切换按钮：

* 开启后，搜索框提示变为「用自然语言描述想找的影片…」。输入如「找几部有剧情、女主是老师的」之类的话，AI 会把意图解析成结构化条件（类型 / 女优 / 厂商 / 系列 / 年份 / 关键词），自动套用筛选并展示结果。
* 若 AI 未启用或解析失败，自动退回普通关键词检索，不影响正常使用。

## 续看、相似推荐与片单（发现与策展）

这一组功能让「逛」更有连续性：上次看到哪、还想看类似的、以及把喜欢的归档成片单。

### 续看进度

* 打开任意作品详情，操作区下方有 **观看进度** 滑块（0–100%）。拖动到看到的位置，点 **保存**，即记录进度（按影片时长换算成秒）。
* 首页「馆藏」顶部出现 **⏯ 继续观看** 货架，带进度条，点卡片直接从该作品详情继续；点 **清空进度** 可一次性清除所有进度（仅清进度，不删影片）。
* 标记了进度的影片会同时被记为「已看」。

### 相似推荐（猜你喜欢）

* 详情抽屉底部「猜你喜欢」按 **共演女优(权重10) / 同类型(4) / 同厂商(3) / 同系列(3) / 同导演(2)** 加权打分，给出最像的作品。
* 点任意推荐卡片即可跳到该作品详情，继续深挖。

### 自建片单

* 顶部切到 **片单** 标签页：输入名称点 **新建片单**，即可创建「年度十佳」「周末片单」「最强单体」等专属片单。
* 在任意作品详情点 **＋ 加入片单**，弹出片单列表，选一个加入；也可「新建并加入」。
* 进入某个片单：可 **重命名 / 删除片单**，卡片悬停点右上角 **✕** 移出该片单，点 **导出 CSV** 把片单内容导出为表格。

## 11. 观看历史与我的观影（了解你的喜好）

这套功能把「看过」从单个进度点升级成一条事件流，方便沉淀与复盘。

### 会话级观看历史

* 每次点 **▶ 系统播放** 或 **🎬 内置播放**，都会记一场：开始 / 结束时间、本次观看秒数、是否看完。
* **系统播放器也能记录详细历史（零配置）**：点「系统播放」后，后端会在后台持续探测「影片文件是否仍被播放器占用」，把占用的时间段合并为观看区间——因此**任何系统播放器（VLC / PotPlayer / MPC / mpv …）**都会自动记下「看了多久」与「哪几段时间段」，且不受浏览器解码能力限制（MKV / H.265 也能记录）。
* 作品详情抽屉底部「**观看历史**」区，展示该片 **场次数量、累计观看时长、覆盖率**，并逐场列出时间、来源（系统 / 内置）与分段覆盖条。

### 真实分段（内置播放器，A 档）

* 详情页点 **🎬 内置播放**：浏览器直接流式播放该影片（`/stream` 接口支持断点续传），并实时记录你**实际观看的区间** `[起点, 终点]`。暂停 / 拖拽 / 看完都会落库，关闭或看完时弹出「已记录本次观看（分段）」。
* 「观看历史」里的覆盖条就是由这些分段拼出的——一眼看出你**看了哪几段**、跳过哪些（如片头片尾）。
* 若影片是 MKV / H.265 等浏览器无法直接解码的格式，**直接点「系统播放」即可**——由系统播放器解码，且后端监控会自动记录观看时长与分段（无需内置播放器支持）。内置播放器适合浏览器能直接解码的 MP4 / WebM 等格式，可做帧级精确分段。

### 我的观影（偏好分析，B 档）

* 顶部切到 **我的观影** 标签，基于**真实观看时长**（而非收藏）聚合你的口味：
  * 概览：总观看时长 / 总场次 / 看过影片数 / 活跃天数 / 日均场次 / 场均时长。
  * **偏好画像**：类型 / 女优 / 厂商 / 系列 / 导演，按观看秒数加权排序（比收藏更真实）。
  * **活跃时段**热力图：看你是白天党还是夜猫子。
  * **观看最多的影片** 与 **最近观看** 列表，点任意条目可直达详情。

## 12. 常见问题

**扫描不到文件？**
检查「最小文件体积」（默认 100MB）和「视频扩展名」；测试小文件把体积设为 0。

**封面全是占位图？**
封面优先级：同目录图片 → 元数据源 URL → 手动上传 → 番号占位图。可在设置页「批量嗅探本地封面」，或在详情页用「封面地址 / 上传」指定。

**「移除记录」会删视频吗？**
不会，只删数据库记录。

**数据怎么备份 / 迁移？**
整个 `data/` 目录拷走即可（打包版在 `exe` 同级的 `data/`，源码版在项目根的 `data/`）。

**评分 / 收藏 / 想看清单存在哪？**
都在本地 `library.db`，不上传任何信息。

**换了封面但列表/详情图没更新？**
封面接口已改为不缓存（`no-cache`）。若仍显示旧图，请**硬刷新**浏览器（Windows：`Ctrl+Shift+R` / Mac：`Cmd+Shift+R`）以清除浏览器对旧封面的本地缓存。

**AI 功能用不了？**
先在「设置 → AI 增强」启用并填好 Base URL / 模型；本地 Ollama 还需确认 `ollama pull <模型>` 已执行、`http://127.0.0.1:11434/v1` 可访问。详情页与搜索框的 AI 按钮仅在启用后出现。

## 13. 近期新功能速览

* **预览图墙**：打开作品详情，点抽屉里的「生成预览图」会调用 `ffmpeg` 在影片中等距抽 6 帧，生成缩略图墙；卡片下方出现「预览」缩略图行，点开看大图。未配置 `ffmpeg` 时会提示「请在设置填写 ffmpeg 路径」。路径在 **设置 → ffmpeg 路径** 填写（支持绝对路径或系统 PATH 可用的 `ffmpeg.exe`）。
* **滑动评分**：顶栏点「滑动评分」标签页，先选排序（最近添加 / 评分升序 / 未看 / 随机），再点「开始」。逐张展示影片：**左滑 / ←** 跳过，**右滑 / →** 加入「想看清单」，**F** 收藏；看完自动出下一张，适合大批量盲筛。
* **关注女优**：女优墙或女优详情页点头像上的星标可「关注/取关」。女优墙筛选条新增「仅关注」开关，并可按「关注优先」排序。
* **排行榜**：顶栏「排行榜」标签页，按 **观看时长 / 评分 / 收藏 / 播放次数** 四种维度排 Top 影片（观看时长来自真实观看历史）；点任意行进详情。
* **批量编辑增强**：画廊多选后，批量栏新增「评分 / 已看 / 未看 / 类型 / 女优」按钮——评分直接赋值；类型与女优可【追加】到原关系或【替换】掉原关系。
* **文件体检**：**设置 → 存储** 页点「开始体检」，扫描五类问题并汇总：缺失文件、缺封面、未识别番号、疑似重复（两片大小相同）、分片不完整（有 `-cd1` 但缺 `-cd2`）。点栏目可展开明细并跳转。注：更聚焦元数据质量的「未识别番号 / 占位图」修复已收敛到 **数据健康** 页（见第 9 节）。
* **统计可视化增强**：**统计** 页新增「标签云」（按作品数缩放字号）、「时长分布（按年）」柱状图；原有的观看日历热力图已接入真实观看时段。
* **智能清单**：**片单** 页点「新建智能清单」，按规则自动聚合影片——条件可选「未看 / 想看 / 收藏」，设评分下限，限制类型与女优，再选排序。智能清单随馆藏自动更新，不支持手动增减影片。
* **番号识别增强**：支持 `IRO061C`、普通电影 `SONE 760CH` 等「字母紧贴数字 / 带版本字母」命名，自动解析为 `IRO-061` / `SONE-760`。
* **数据健康页**：顶栏「管理 → 数据健康」新增六类体检（缺失文件 / 分片不完整 / 缺封面 / 占位图 / 未识别番号 / 疑似重复），支持一键「重解析番号」「刮削缺失」。
* **AI 增强（可选）**：兼容 OpenAI 协议的任意端点（云端 / 国产中转 / 本地 Ollama），详情页可「AI 生成简介」「AI 补充标签」，搜索框开启后支持「语义搜索」自然语言检索（见第 10 节）。
* **封面缓存修复**：封面接口改为 `no-cache`，更换封面硬刷新即生效。

## 14. 使用须知

* 本工具仅用于管理 **用户自己合法持有** 的本地媒体文件，不提供、不索引、不下载任何影片内容。
* 联网数据源需由使用者自行配置，请遵守目标站点的服务条款及所在地区法律法规。

## 15. 近期更新记录

* **番号识别增强**：支持 `IRO061C`、普通电影 `SONE 760CH` 之类「字母紧贴数字 / 带版本字母」的命名，自动解析为 `IRO-061` / `SONE-760`。
* **封面缓存修复**：封面接口改为 `no-cache`，更换封面后硬刷新即可生效，不再被浏览器长期缓存旧图。
* **暗色主题修复**：`color-scheme` 已跟随主题切换，设置页等原生表单控件在暗色下文字清晰可读。
* **数据健康页**：新增六类数据体检（缺失文件 / 分片不完整 / 缺封面 / 占位图 / 未识别番号 / 疑似重复），支持一键「重解析番号」「刮削缺失」。
* **AI 增强（可选）**：兼容 OpenAI 协议的任意端点（云端 / 国产中转 / 本地 Ollama），详情页可「AI 生成简介」「AI 补充标签」，搜索框支持「语义搜索」自然语言检索。
