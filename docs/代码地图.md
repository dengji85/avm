- 改路由后导出 `app.openapi()['paths']` 逐条比对，必须 0 缺失。

## 6. 后台任务与定时器

| 任务 | 触发 | 实现 |
|---|---|---|
| 自动扫描媒体库 | `library.auto_scan_interval` | `main.py::_start_auto_scan` → `scanner.run_scan(incremental=True)`，与手动扫描共享 `SCAN` 锁 |
| 在线来源巡检 | `stream.auto_renew_interval`（默认 10 分钟） | `main.py::_start_auto_renew` → `source_renew_job.start()` |
| 订阅新片扫描 | `subscription.scan_mode` = interval（`scan_interval_minutes`，默认 360 分钟 ± 抖动）/ cron（`scan_cron`，默认 `0 8 * * *`）；`catch_up_on_start` 决定关机错过是否启动补扫 | `main.py::_start_subscription_scan` 每 30 秒问一次 `subscription_schedule.should_run()` → `subscription_job.start()`（手动触发同入口；目标行「补抓历史」传 `mode=backfill`）；状态落 `data/subscription_schedule.json`，改配置 1 分钟内生效；`scan_all` 按站点分组并行（同站串行 + 2s 间隔，跨站最多 3 组），完成时回报本轮归档条数 `archived` |
| 订阅在线资源探测 | 手动（订阅页「检查在线资源」）/ 扫描后自动 / 卡片单条「重新探测」 | `subscription_probe_job.py`（单次 ≤200 条，条间 1.2s；非 force 只补未探测或超过 `probe_ttl_days` 的结论，且跳过 `confirm_count < 2` 的待确认条目并计入 `skipped`；单条重探走 `POST /api/subscriptions/findings/{id}/probe` 同步调用） |
| 批量海报 | 手动 | `poster_job.py` |
| 单部字幕翻译 | 手动 | `translate_job.py` |
| 批量广告检测 | 手动 | `ad_job.py` |
| AI 批次 | 手动 | `ai_jobs.py` |
| 扫描 / 抓取进度 | 手动 | `jobs.py` |

线程池：`submit_long` 2 线程（分钟级），`submit_task` 4 线程（秒级）。**分钟级任务用短池会饿死交互请求**。

长任务标准契约：`_JOB` 状态字典（`running/total/done/percent/message/cancel`）、`start()` 用 `submit_long`、`state()` 返回副本、`cancel()` 置标志、重复触发返回同一任务。

## 7. 刮削链路与数据源

```
文件名 → parser（番号）
      → scraper（编排：按优先级试 provider）
      → providers/*（fetch 单片）
      → store（写库）
      → images（封面）
      → nfo_writer（可选落盘）
```

| provider | 能力 |
|---|---|
| `javbus` | 按番号，搜索页兜底 |
| `javdb` | 按番号 |
| `avwiki` | 按番号 |
| `fc2db` | FC2 番号 |
| `metatube` | 外部引擎（需启用） |
| `local_nfo` | 读本地 NFO |
| `http_html` / `http_json` | 通用抓取基类 |

统一基类 `providers/base.py`：`handles / excludes / can_handle / fetch(movie)`。新增源 = 新增文件 + 注册，不把站点逻辑写进 `scraper.py`。

## 9. 常见改动落点

| 你要做的事 | 改哪里 |
|---|---|
| 新增 HTTP 接口 | `app/routers/<域>.py`；没有该域才新建；`api.py` 只做挂载 |
| 新增站点刮削源 | `app/providers/` 新文件 + 注册 |
| 新增分钟级任务 | 新建 `app/xxx_job.py`（照 `source_renew_job.py`），`submit_long`，可取消，带百分比 |
| 新增秒级任务 | 直接 `submit_task()` |
| 新增配置项 | `config.py` + `.get()` + `SettingsView` + 四语言 |
| 新增数据表/列 | `db.py` 迁移段，幂等 |
| 新增页面 | `views/*.vue` + `App.vue` 的 `VIEWS` + 导航 + `api.js` + 四语言 |
| 新增长任务前端进度 | 复用 `useTasks`，1 秒轮询；库外任务（如订阅扫描/探测）只做「可见 + 可取消」，不进历史、不参与总进度 |
| 新增 AI 能力 | `ai.py`（说什么）→ `ai_core.py`（怎么调）→ `ai_prompts.py`（提示词）→ 必要时 `ai_jobs.py` |
| 新增在线来源能力 | `ingest.py` + `movie_sources` + `stream_verify.py` |
| 改播放器 | `VideoPlayer.vue` + `stream_cache.py` / `stream_verify.py`；注意 video.js 相关兼容问题 |
