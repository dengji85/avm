# 片匣 · 打包与分发指南

把源码打成 **单个 exe、双击即运行** 的 Windows 程序，方便在没有 Python 环境的机器上使用，也方便整体拷贝分发。

---

## 1. 环境准备

```bash
# 建议 Python 3.11（与开发环境一致，避免 _internal 体积或兼容问题）
pip install -r requirements.txt
pip install pyinstaller        # 打包脚本依赖
```

> `build.py` 已经把运行本项目所需的全部第三方库写进 `requirements.txt`（fastapi / uvicorn / requests / beautifulsoup4 / python-multipart），`pyinstaller` 单独装即可。

---

## 2. 一键打包

```bash
python build.py
```

`build.py` 内部调用 PyInstaller，关键参数：

* `--name AVM`：产物名。
* `--onefile`：打包成**单个 exe 文件**（而非文件夹），分发与升级都只需这一个 `AVM.exe`；代价是首次启动需解包到临时目录，比 `--onedir` 稍慢。
* `--add-data web_dist;web_dist`：把 `web_dist/` 前端静态资源打包进程序。
* `--collect-submodules app`：递归收集 `app/` 下所有子模块（含 `providers/` 数据源与 `ai.py` AI 增强模块）。
* 一系列 `--hidden-import`：补齐 uvicorn / multipart / email / charset_normalizer 等运行期才导入的模块。
* AI 增强依赖 `requests`（已在 `requirements.txt`），无需额外打包参数；打包后「设置 → AI 增强」可正常配置并调用云端 / 本地 Ollama 端点。
* `--clean --noconfirm`：每次清缓存、覆盖旧产物。

产物：

```
dist/AVM.exe       # 单个可执行文件，双击启动并自动开浏览器；前端资源已内嵌，无需任何附带文件
```
> 运行期数据 `data/` 在 **`AVM.exe` 同级目录**自动创建（见第 4 节），不打包进 exe。

---

## 3. 冻结环境下的路径

`app/config.py` 在检测到 `sys.frozen` 时会切换根目录：

```python
if getattr(sys, "frozen", False):
    BASE_DIR = Path(sys.executable).resolve().parent      # exe 同级
    _MEIPASS = Path(getattr(sys, "_MEIPASS", str(BASE_DIR)))
    WEB_DIR   = _MEIPASS / "web_dist"                     # 前端资源内嵌于 exe，运行时解包到临时目录
else:
    BASE_DIR = Path(__file__).resolve().parent.parent
    WEB_DIR   = BASE_DIR / "web"
DATA_DIR = BASE_DIR / "data"                              # 数据在 exe 同级 data/
```

要点：

* **数据**（`library.db` / `covers/` / `avatars/` / `config.json`）放在 `exe` 同级 `data/`，便于备份与迁移。
* **前端** 已内嵌进 `AVM.exe`，运行时由 PyInstaller 解包到临时目录，程序自动读取，无需任何额外文件。

---

## 4. 内置馆藏（可选）

若希望分发出去就自带现有收藏，把开发目录的 `data/` 放到 `AVM.exe` 同级：

```powershell
Copy-Item -Recurse -Force data  dist\data
```

新机器双击 `AVM.exe` 即可直接看到你的馆藏，无需重新扫描。

> 若不想内置，只分发单个 `AVM.exe` 即可，对方首次启动会在 exe 同级自动创建空 `data/`，再在「设置」里加媒体库目录并扫描即可。

---

## 5. 启动与停止

* 双击 `AVM.exe` → **打开一个控制台窗口并实时输出日志**，自动打开浏览器 `http://127.0.0.1:8770`。
* 关闭方式：直接关闭控制台窗口，或在窗口内按 `Ctrl+C` 优雅退出服务。
* 若同机已有一个实例在跑（默认 8770 端口被占用），再次双击会提示端口占用而退出，不会重复启动。
* 命令行参数同样有效：`AVM.exe --port 9000 --host 0.0.0.0 --no-browser`。
* 需要控制台调试日志时，默认就是控制台模式，直接双击即可看到日志。

## 6. 验证产物

打包后可做最小冒烟测试（以 8772 端口为例）：

```powershell
$p = Start-Process -FilePath "dist\AVM.exe" -ArgumentList "--no-browser","--port","8772" -PassThru
Start-Sleep -Seconds 6
Invoke-WebRequest -Uri "http://127.0.0.1:8772/" -UseBasicParsing          # 期望 200
Invoke-WebRequest -Uri "http://127.0.0.1:8772/api/actresses?limit=1" -UseBasicParsing  # 期望 200 + JSON
Stop-Process -Id $p.Id -Force
```

## 7. 常见问题

**体积过大？**
单个 exe 约 20+ MB（已内嵌 Python 解释器、第三方库与前端资源），主要来自 Python 解释器与第三方库，属于正常。脚本已默认开启 `upx=True` 进一步压缩；如仍需更小可改用 `--onedir`（牺牲单文件便利性换体积/启动速度）。

**杀毒软件误报？**
PyInstaller 打包的程序常被部分杀软误报。可加入白名单，或对 exe 做代码签名。

**换电脑后封面/头像丢了？**
因为封面缓存在 `data/covers`、头像在 `data/avatars`，整目录拷贝即可，不要只拷 `library.db`。

**想打 Linux / macOS 包？**
在对应系统上重跑 `python build.py` 即可（数据源、前端逻辑跨平台一致；路径逻辑已用 `pathlib` 处理）。

**`_internal` 目录去哪了？**
单文件（`--onefile`）模式下没有 `_internal/` 目录——所有依赖与前端资源都已内嵌进 `AVM.exe`，运行时自动解包到临时目录。你拿到的就是一个 `AVM.exe` 文件，无需任何附带目录。
