# 扩展组件手册（FFmpeg / 语音识别）

主程序保持单文件小体积，FFmpeg 与语音识别（faster-whisper）作为**可选组件**按需安装。
本文按平台说明每种环境下怎么装、怎么用、出问题怎么办。

入口：**设置 → 扩展组件**（tab）。装完即生效，无需重启服务。

## 组件总览

| 组件 | 作用 | 体积 | 不装会怎样 |
|---|---|---|---|
| FFmpeg | 封面抽帧、预览图、内嵌字幕探测/抽取、浏览器播放转封装、语音提取的音轨抽取 | 约 100MB | 这些功能不可用（刮削仍能用网络图源） |
| 语音识别组件 | faster-whisper 运行库 | 约 170MB | 详情页「提取对白」不可用 |
| 语音模型 small | 识别模型（CTranslate2 格式） | 约 460MB | 同上；组件 + 模型都装好才能提取对白 |
| 语音模型 medium | 更准但慢约 3 倍 | 约 1.5GB | 可选，与 small 二选一使用 |

页面上的状态徽标：

- **已就绪**（绿）：可用，并显示版本、来源、磁盘占用
- **未安装**：显示「一键安装 / 手动导入」按钮，以及不装的影响
- **安装中**：进度条 + 速度 + 已下载/总量 + 日志尾部 + 取消

通用规则：

- **路径优先级**永远是「用户显式配置 > 组件目录 > 系统 PATH」。
  语音设置里手填过的路径（libs_dir / model_dir / ffmpeg_path）不受组件安装影响。
- **一键安装失败会自动换源**（FFmpeg 内置多个下载源）；也可用手动导入兜底。
- 同一时间只允许一个安装任务；下载支持取消与断点续传。
- 组件默认装在 `data/ext/`（容器内 `/data/ext`），随数据目录持久化，
  程序升级、镜像更新都不会丢。

## Windows 便携版（单文件 exe）

### FFmpeg

1. 设置 → 扩展组件 → FFmpeg 卡 → **一键安装**。
   自动下载官方静态构建（gyan.dev，失败自动换 BtbN 源）并解压到 `data/ext/ffmpeg/bin`。
2. 没有外网？手动导入：
   - 自己下载 `ffmpeg-release-essentials.zip`（gyan.dev 或 BtbN）；
   - 点 FFmpeg 卡的**手动导入**，填 zip 的完整路径（或已解压目录）；
   - 校验通过（能跑 ffmpeg -version）即登记。

也可以完全不用组件页：把 ffmpeg.exe 放进 PATH，或在设置里填 `ffmpeg_path`。

### 语音识别（组件 + 模型）

便携版 exe 内没有 pip，语音组件有三种装法：

**方式 A：页面上下载预打包 zip**（推荐，发布页提供 asr-libs-cp311-win64.zip 时可用）
直接点语音识别组件卡的「一键安装」。

**方式 B：手动导入现成目录**
在任何一台有 Python 3.11 x64 的电脑上：

    pip install --target D:\avm-asr\libs faster-whisper==1.2.1 ctranslate2==4.5.0

然后把 `D:\avm-asr\libs` 填进语音识别组件卡的**手动导入**（会拷贝到 `data/ext/asr-libs`）；
或者不拷贝，直接在「语音识别设置 → 高级」里把 libs_dir 指到 `D:\avm-asr\libs`。

**方式 C：只用配置**
同上，高级设置里手填 libs_dir 即可，组件页会显示「已就绪 · 使用自定义路径」。

**模型**：点「语音模型 small」卡的**一键安装**（走 ModelScope 镜像，国内直连可用），
落到 `data/models/faster-whisper-small`。也可以自己下载后用**手动导入**
（给 model.bin 所在目录即可，大文件移动不复制）。
medium 暂无已验证的在线源，请手动导入。

### 磁盘紧张

`data/ext` 默认在数据目录所在盘。换盘：把配置里的 `ext.dir` 指到如
`D:\program my\avm-ext`（模型目录另见 asr.model_dir，临时音轨目录 asr.tmp_dir）。

## 源码 / 开发环境运行

与便携版基本一致，两点差异：

- 本机 Python 有 pip → 语音识别组件的「一键安装」直接执行 pip --target 安装，
  国内网络慢可在安装时用镜像源（清华 PyPI）。
- 项目自带的 tools/ffmpeg/bin/ffmpeg.exe 会作为兜底被自动检测到（显示「来自便携包」），
  可以完全不装 FFmpeg 组件。

命令行一键装齐（等价做法）：

    pip install -r requirements-asr.txt
    python tools/fetch_asr_model.py            # 模型 → data/models/faster-whisper-small

## Docker / NAS

| 镜像 / 构建方式 | FFmpeg | 语音组件 |
|---|---|---|
| latest（默认，GitHub Actions 多架构） | 预装（apt） | 未装，页面上装 |
| 自建 WITH_ASR=1 | 预装 | 构建时 pip 装进系统环境 |

### 容器内页面安装（推荐）

容器里有 pip，且 /data 是持久化卷：

1. FFmpeg：不用装——组件页显示「已就绪 · 来自系统 PATH」（镜像内置）。
2. 语音识别组件：点「一键安装」，装到 **/data/ext/asr-libs**（在挂载卷上，
   镜像升级 / 换 tag 都不会丢）。
3. 语音模型：点「一键安装」，落到 **/data/models/faster-whisper-small**。

### 挂载预下载内容（离线 NAS / 多实例共享）

    volumes:
      - ./data:/data
      - /mnt/nas/avm-models:/data/models        # 预先放好 faster-whisper-small/
      # 可选：组件目录也指到宿主机，多个容器共用
      # - /mnt/nas/avm-ext:/data/ext

模型目录里需直接有 model.bin（连同 config.json、tokenizer.json、vocabulary.txt）。

### 自建镜像（离线部署）

    docker build --build-arg WITH_ASR=1 -t avm:asr .

构建时把依赖装进镜像（约 +170MB，仅 x86_64 验证过；ARM NAS 建议用页面安装实测），
模型仍放挂载卷，不随镜像。

### 注意

- 容器内数据根是 /data：组件在 /data/ext、模型在 /data/models，
  与 Windows 的 data/ext、data/models 一一对应。
- 组件想挪到别的挂载卷：环境变量 AVM_EXT_DIR=/mnt/nas/avm-ext。

## 完全离线 / 内网环境

三样东西都可以在能上网的机器上准备好，拷进去手动导入：

| 组件 | 准备方法 | 导入物 |
|---|---|---|
| FFmpeg | 下载 gyan.dev / BtbN / johnvansickle 的压缩包 | zip（或 tar.xz）或解压目录 |
| 语音组件 | `python tools/build_asr_zip.py`（CI 打 tag 时也会自动产出）或 pip install --target | 生成的 asr-libs-*.zip |
| 模型 | 从 ModelScope 下载 pengzhendong/faster-whisper-small 的 4 个文件 | 含 model.bin 的目录 |

导入入口在各组件卡的「手动导入」，填**服务端机器**可访问的完整路径。
导入时会做校验（能运行 / 找得到包 / 有 model.bin），校验不过会明确报错，不会装一半。

也可以跳过导入，直接用配置指路：ffmpeg_path、asr.libs_dir、asr.model_dir。

## 常见问题

**点了安装一直 0% / 没反应？**
看卡片上的日志尾部。多数是下载源连不上：FFmpeg 会自动换源重试；
语音组件在打包版里走预打包 zip，若发布页还没有该文件，请用「手动导入」。

**装了 FFmpeg 但显示未安装？**
先点「重新检测」。若仍不行：检查是否在设置里填过 ffmpeg_path 且指向了不存在的文件
（配置优先级最高，会盖过组件目录）；手动导入的目录里必须有 ffmpeg.exe 与 ffprobe.exe。

**语音组件显示已就绪，但提取对白提示缺模型？**
组件（运行库）和模型是两样东西，两张卡都要就绪。模型看「语音模型 small」卡的状态；
自定义过 asr.model_dir 的，模型要放在那个目录下。

**下载到一半中断了？**
重新点「一键安装」即可，.part 断点续传接着下，不会从头再来。

**卸载会影响什么？**
只删除组件目录（data/ext 下对应文件夹）并清登记；你在设置里手填过的路径、
已生成的数据（封面、对白文本）都不受影响。卸载后对应功能回到「不可用」状态。

**来源徽标是什么意思？**
「来自系统 PATH / 来自系统 Python」= 环境里本来就有；「使用自定义路径」= 你在设置里填过；
「来自便携包」= 程序目录 tools/ffmpeg 自带。这些情况下组件页只读展示，
「卸载」按钮只在组件是本页安装（data/ext）时出现。

## 配置项参考

| 配置 | 位置 | 默认 | 说明 |
|---|---|---|---|
| ext.dir | config.json | data/ext | 组件根目录（ffmpeg、asr-libs） |
| ext.asr_libs_url | config.json | 内置发布页地址 | 语音组件预打包 zip 的下载地址，可指向自建源 |
| AVM_EXT_DIR | 环境变量 | - | 组件根目录，优先于 ext.dir |
| AVM_ASR_LIBS | 环境变量 | - | 语音组件依赖目录，优先于 asr.libs_dir |
| AVM_ASR_MODEL_DIR | 环境变量 | - | 模型根目录，优先于 asr.model_dir |
| ffmpeg_path | config.json | - | FFmpeg 可执行文件路径，优先级最高。编辑入口：设置 → 扩展组件 → FFmpeg → 高级 |
| asr.libs_dir / asr.model_dir / asr.tmp_dir | config.json | data/ext/asr-libs、data/models、data/asr | 见「语音识别设置 → 高级」 |
