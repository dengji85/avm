## 😩 こんな「コレクターあるある」に悩んでいませんか？

- ドライブを何度も買い替え、**数千本ためたのに観たい1、2本が見つからない**
- 同じ作品がライブラリに**7、8個も重複**：無修正版・有修正版・字幕版・再エンコ版……容量を食う上に区別がつかない
- `IRO061C`、`SONE-760CH`、`300MAAN-123` のような**独自命名**は、通常のツールでは一切認識できない
- 表紙が取り違えられ、スクレイピング失敗、**素人ものは表紙すらない**
- 「前観た先生役の女優のあれ」——**頭で思い出そうとしても出てこない**
- 途中で中断、**進捗が消えて次回また最初から**
- プライバシー漏洩やサイト閉鎖、PC交換でコレクションが全部消えるのが怖い

**FilmBox は、そうした悩みを本気で治すために作られました。**

## ✅ なぜ FilmBox が必要なのか

一言で：**あなたのコレクションには、ただのフォルダの山ではなく、ちゃんとした「図書館」がふさわしい。**

| FilmBoxなし | FilmBoxあり |
| --- | --- |
| ファイル名が乱雑で記憶頼みの検索 | 品番の自動正規化、ファセット絞り込み＋意味検索で一瞬で特定 |
| 同じ作品が7、8個重複 | 内容レベルの重複排除＋マルチバージョン統合で最良版のみ保持 |
| 表紙欠け、スクレイピング失敗 | プラガブルな複数ソース＋相互フォールバック。品番付き素人ものも表紙補完 |
| 観たかどうかは当てずっぽう | ゼロ設定の再生監視で進捗を自動記録、観たか未観か一目瞭然 |
| コレクションが他人のサーバー上 | 完全ローカル、アカウント不要、通信報告なし、データをコピーするだけで動く |

> **完全にローカルで動作し、既定では通信報告しません。AI もあなた自身のエンドポイント経由——キーは設定したアドレスにのみ送信されます。コレクションは常にあなたのもの。**

## ✨ コア機能

<p align="center">
  <img src="docs/assets/avm影片库.PNG" alt="AVM 概要" width="1100"/>
</p>

- **🗂 自動スキャンでライブラリ構築**: ディレクトリを再帰スキャンし、サイト/アップローダー/技術的ノイズを除去、sample/予告/ゴミ箱等をスキップ。小さなプレビュー動画は無視。
- **🔍 独自品番の認識**: `IRO061C`、`SONE-760CH`、`300MAAN-123` のような「文字と数字がくっつき、バージョン末尾付き」の命名も `IRO-061` / `SONE-760` に正規化し、字幕(`-C`)/無修正(`-U`)/VR/4K/分割を自動判定。
- **🧹 マルチバージョン統合＋コンテンツ重複排除**: 無修正/有修正/ディレクターズカット/字幕版を同一作品に自動統合。「サイズ＋内容ハッシュ」で正確な重複を特定。**明らかな分割（`-cd1`/`(1)`/`-a`）はセットとして認識し、決して重複と誤判定・誤削除しません。**
- **🖼 メタデータ・スクレイピング**: プラガブルなデータソース（JavBus / JavDB / AV-Wiki / ローカル `.nfo` / カスタム JSON・HTML ルール）で表紙・女優・ジャンル・シリーズ・メーカー・評価・あらすじを補完。取得できなくても手動補完可。
- **🤖 任意の AI 拡張**: 任意の OpenAI プロトコル端末に対応——クラウドはキー入力、ローカル Ollama はキー不要。自然言語で「ストーリー重視で女優が先生役のを数本」と検索すれば即抽出。詳細ページでワンクリックあらすじ生成・タグ補完。AI 無効時は通常検索に自動フォールバック。
- **📺 ゼロ設定の再生監視**: VLC / PotPlayer / MPC / mpv にファイルを渡すだけで、バックグラウンドが「どれだけ観たか・どこまで・完観か」を自動記録。再開位置・類似推奨・「マイ視聴」嗜好分析で次の一本に迷わない。
- **🩺 データ健康診断**: 6 種のメディア問題（ファイル欠け / 分割不完全 / 表紙欠け / 代替画像 / 未認識品番 / 疑わしき重複）＋4 種の低品質スクリーニング（広告サンプル / 低ビットレート / 同品番低品質版 / 破損）。ワンクリックで最良版保持・冗長クリーンアップ。
- **🎴 ギャラリー・キュレーション**: カードウォール＋女優ウォール＋タグクラウド＋スマートプレイリスト（ルールで自動集約）＋類似推奨で、「溜め」を「観られる」に変える。
- **📡 リモートアクセス**: スマホ／LAN 端末で QR コードを読むだけで即開通。トークン認証＋ファイアウォール許可ヒント（`edge=yes` でファイアウォール全体を切らずに通るエッジ貫通）。
- **⏱ 定期自動スキャン**: 新作ダウンロード後に周期で自動増分取り込み。毎回手動スキャン不要。
- **💬 字幕マッチング**: ブラウザで字幕ファイルを直接選んでアップロード。品番でライブラリ内作品に合わせてワンクリック整列リネーム（元ファイルを残す複製にも対応）。

## 🆚 他のツールではなく FilmBox を選ぶ理由

市場の選択肢は大きく二つ：**汎用メディア・スクレイパー**（TinyMediaManager、MediaElch、XBVR 等——映画・TV 中心で AV はかろうじて互換）と**各種 JAV 小スクリプト**（単機能・UI なし）。FilmBox は **AV コレクションのために領域特化したワンストップのローカル・ライブラリ** です。

| 本当に気になる点 | 汎用スクレイパー | 自作スクリプト | **FilmBox AVM** |
| --- | --- | --- | --- |
| **独自品番を認識する？** | 通常は正規命名のみ | 単ソース検索、正規化なし | 7 クラスの専用ルール解析、正規化＋タグ認識 |
| **同じ作品が7個も重複しない？** | 手動統合が必要 | ほぼ非対応 | 自動統合＋内容レベル重複排除、分割は誤判定しない |
| **AV メタデータは正確？** | AV 編目が弱く表紙が狂いやすい | 単サイト依存、落ちたら空 | 複数ソース可插抜＋相互フォールバック。品番付き素人ものも表紙補完 |
| **強力な反ボットソース（AV-Wiki）？** | 対象外 | 手動でブラウザ養生が必要 | 内蔵 CDP スクレイピング、常駐 headless Chrome が認証ページを自動回避（本機に Chrome 要。無い場合は通常リクエストへ自動フォールバック） |
| **「フォルダ」ではなく「作品」でキュレーション？** | フォルダ中心 | リストのみ | 女優ウォール / タグクラウド / スマートプレイリスト / 類似推奨 |
| **中断から再開できる？** | プレイヤー plugin 要 | なし | 任意のシステムプレイヤーをゼロ設定監視、進捗を自動記録 |
| **ライブラリの汚れが一目で分かる？** | ほぼなし | なし | 6 種診断＋4 種低品質スクリーニング、ワンクリック清掃 |
| **AI 意味検索？** | 多くはなし | なし | 任意。OpenAI 端末 / ローカル Ollama 対応 |
| **プライバシー＆配備？** | デスクトップ GUI / 常駐サービス | バラバラなスクリプト | 純ローカル Web、アカウント不要、単コマンドで exe 化（インストール不要） |

> **要するに：これは「動画が再生できるもう一つの Web ページ」ではなく、AV コレクションという特殊領域に大きく適合（品番・重複排除・素人・視聴回帰・健康診断）したローカル・ライブラリです。**

## 🌟 1.11.0 のハイライト

> リリース日：2026-08-15

- **🔎 スクレイプ失敗理由パネル**: メンテセンターに「スクレイプ失敗理由」Tab を追加。これまでの「失敗＝ブラックボックス」を可視化診断に。失敗した各作品に**ソース別明細**（各データソースの状態＋理由）を表示し、全体分類と対処を提案。失敗は「反ボット遮断／通信エラー／ソースに該当作品なし／解析失敗／品番異常」の 5 類に集計され、「ソースが落ちた」か「本当に存在しない」か一目で判別。
- **ワンクリック再試行＋別ソース再取得**: 一時的な通信/遮断項目のみ再実行（安定した欠落はそのまま）、または作品を選んで特定データソース（av-wiki 等）を指定して再取得し、遮断されたサイトを迂回。
- **💬 字幕マッチングがファイル直接選択に**: メンテページで「ファイルを選択」をクリックするだけで字幕をアップロード。品番でライブラリ内作品に合わせてワンクリック整列リネーム（元ファイルを残す複製に対応）。
- **🧹 重複検出の分割認識を強化**: `_1`/`-cd1`/`.part3` に加え、括弧 `(1)`、`[2]`、単文字 `-a`、解像度付 `1080p-1` などの明らかな分割を検出。品番の末尾数字が連番と誤判定されなくなりました。
- **🔔 バージョン確認（About）**: GitHub Releases と連携し、現在/最新バージョンとリリースノートを表示。更新元のカスタムに対応。
- **📡 リモートアクセスを独立タブに**: 複数アドレスをクリック切替で QR 生成、トークンカスタム、ファイアウォール許可ヒント。
- **⏱ 定期自動スキャン**: 分単位の周期でバックグラウンド増分取り込み。

全文は **[`CHANGELOG.md`](CHANGELOG.md)** を参照。

## 📦 ダウンロード & インストール

自分でビルドしたくない？ リリースパッケージを直接ダウンロード（Windows 単フォルダ zip、展開して即実行）：

<p align="center">
  <a href="https://github.com/dengji85/avm/releases/latest">
    <img src="https://img.shields.io/github/v/release/dengji85/avm?label=最新版をダウンロード&color=1f6feb" alt="GitHub Release"/>
  </a>
</p>

1. **[Releases](https://github.com/dengji85/avm/releases)** から最新の `AVM-win64.zip` をダウンロード。
2. 任意のディレクトリ（例 `D:\AVM\`）に展開し、`AVM.exe` をダブルクリックで起動——自動でブラウザが開き Web UI へ。
3. データ（ライブラリ／表紙／設定）は `data/` ディレクトリにあり、**フォルダごとコピーでバックアップ・移行完了**。

## 🚀 クイックスタート

### 方式1：ソースから実行（開発）

```bash
pip install -r requirements.txt
python run.py serve            # バックエンド http://127.0.0.1:8770
cd web_src && npm install && npm run dev   # フロントエンド http://localhost:5173
```

### 方式2：ビルドしてまとめてホスト

```bash
cd web_src && npm install && npm run build
python run.py serve            # web_dist/ を直接ホスト
```

### インストール不要版としてパッケージ

```bash
python build.py                # dist/片匣/片匣.exe を生成
```

## 🔒 プライバシーとコンプライアンス

- すべてのコレクションデータはローカルにあり、**既定では通信報告しません**。
- 通信が発生するのは：あなたが有効にしたデータソース、およびご自身で設定した AI エンドポイントのみ。
- **合法的に所持する**ローカルファイルの管理のみに使用し、お住まいの地域の法規およびデータソースサイトの利用規約を遵守してください。
